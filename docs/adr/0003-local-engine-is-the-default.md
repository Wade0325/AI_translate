# 預設使用本機引擎，Gemini 為選用替代

給一般使用者的工具通常會選雲端優先，因為不挑硬體；但這個產品處理的多半是私人錄音，送上雲端會有隱私、費用與內容政策的風險。因此預設使用本機引擎（moss-align），硬體門檻只針對本機引擎：NVIDIA 顯卡 12 GB VRAM 以上，建議 16 GB，8 GB 未驗證。Gemini 保留為選用替代，需要使用者自備 API 金鑰；app 本身沒有硬體門檻，但安裝流程以有 GPU 的使用者為準。

## 考慮過的選項

- **Gemini 預設、本機引擎選用**：最容易上手，但等於預設把私人音檔送上雲端，和產品存在的理由相反。

## 後果

- 中文與日文各用哪個本機模型，依評測集的數據決定。
- 沒有 GPU 的電腦也預設本機：轉錄頁寫出本機不能用的原因，並提供「改用 Gemini」，由使用者自己按；不自動改選會上傳音檔的供應商，也不做首次開啟引導（#11 Q1）。
- 顯卡記憶體低於 12 GB 只提示、不擋：8–12 GB 標示未驗證，8 GB 以下警告可能很慢（#11 Q2）。目前的 PyTorch 跑不了的顯卡（GTX 10 系列以前）擋下並說明（#11 Q4）。
- v0.1 的首次佈建不把 GPU 套件和基本執行環境分開下載，沒有 GPU 的電腦也下載約 3.5 GB（#11 Q3）。之後要分開下載時，先回頭看這份決策：有 GPU 的使用者仍是安裝流程的主要對象。
