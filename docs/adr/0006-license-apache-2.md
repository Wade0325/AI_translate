# 採用 Apache-2.0 授權

專案將公開發布，未來也可能自架線上服務或推出企業版。因此程式碼採用 Apache-2.0；隨包散布的第三方元件，要在發布前完成授權盤點，並附上必要的授權文字。

## 考慮過的選項

- **AGPL-3.0**：可以要求別人拿去經營線上服務時公開修改，但企業接受度低。目前還沒有外部使用者，被抄去經營的風險很低，先以採用率為優先。
- **MIT**：README 過去寫的是 MIT，但 repo 一直沒有 LICENSE 檔。Apache-2.0 比 MIT 多了明確的專利授權。

## 後果

- 作者是唯一的著作權人，未來的版本可以改授權，但已經發布的版本維持 Apache-2.0。等線上服務真的要啟動時再重新評估。
