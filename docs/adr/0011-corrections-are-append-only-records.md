# 校正存成只增不改的校正紀錄，校正後版本由原始轉錄加校正紀錄算出

ADR 0007 要求校正同時保存原始轉錄與校正後版本。v0.2 的校正介面還要讓使用者看得到每一次校正、回到其中任何一版，並把「全部取代」這類一次改很多個片段的操作整批復原（#25 的訪談，使用者在 2026-11-15 決定）。因此片段存的就是原始轉錄，寫入後不再改；每一次校正另存一筆校正紀錄，只增不改；校正後版本不另外存，由原始轉錄套上每個片段、每種內容最新的一筆校正紀錄算出來。回到某一版也是再記一筆校正紀錄。重新轉錄則另開新任務：原本的任務和它的校正都留著，校正不搬到新任務，所以重新轉錄不會蓋掉校正。

## 考慮過的選項

- **在片段上多一欄校正後的文字**：比較簡單，讀校正後版本不必計算。但只留得住最後一版，沒有歷程，整批操作也無法復原。
- **重新轉錄沿用同一個任務，把校正搬到新的結果上**：新舊結果的片段數與切法可能不同，校正可能對到別的文字上。

## 後果

- 讀校正後版本要多算一步。下載、校正頁與匯出都從同一個地方算，不各寫各的。
- 校正紀錄以片段為對象（說話者名稱以說話者編號為對象），只記改文字、改說話者、刪掉片段與取說話者名稱。改時間、拆段與併段不在這個模型裡，之後要做得另外設計。
- 同一個任務再完成一次時（Docker 模式的任務被重派、批次從復原入口再結束一次），只要任務已經有校正或確認狀態，新的結果就不寫進片段：校正紀錄對照的原始轉錄不能在使用者背後換掉。
- 校正不會跟著重新轉錄到新任務。要把舊任務的校正用在新任務上，得之後另外做。
