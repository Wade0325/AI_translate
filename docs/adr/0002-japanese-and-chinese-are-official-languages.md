# 官方支援日文與中文，中文一律輸出繁體

第一批使用者處理的是日文（ASMR、影音字幕）與中文（會議、錄音、訪談）音檔，作者自己也只用這兩種語言。因此只有日文與中文是官方支援語言，兩者各有評測集，以「不准變差」把關；中文結果一律輸出繁體。其他語言仍可選，但介面標示「未驗證」。

## 後果

- 品質承諾只涵蓋這兩種語言。要新增官方支援語言，得先為它建立評測集。
- 繁體輸出用台灣的字形與用詞（OpenCC 的 s2twp，已經是台灣用詞的不再換）：逐字稿寫台灣用詞，不一定是講者原本說的詞，照字典換也可能換錯（支持→支援）。評測量的是轉換前的結果，錯字率只量辨識，標準答案照講者實際說的詞寫（#14、#242）。
- 日文永遠不轉：轉錄結果看得出是日文（假名多）時，選了中文或 Auto 也不轉，日文漢字不會被改（#14）。
