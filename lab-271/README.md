> 由 AI 代理（Claude Code）產生。這個資料夾只是暫時放在 `claude/project-thread-0rjpai` 分支上，讓 Wade 的電腦用 git 取得；

## 轉錄結果怎麼來的

- main `1c86505`（#254 合併後），免安裝模式的 app，供應商換成照劇本回傳的假供應商（`scripts/launch_app.py`），
  不去靜音、不切段，劇本的時間就是原音檔的時間。
- 用 Chromium 在轉錄頁轉錄 `subtitle-test.mp4` 兩次（Multi-Speaker 開、關），再從**結果頁**的 Download 下載四種輸出格式
  （`scripts/scenario.cjs`）。History 頁（`/api/v1/history/{uuid}/download/{fmt}`）下載的內容逐位元組相同。
- `subtitles/utf8-lf/` 是 app 原本的輸出：UTF-8、不帶 BOM、換行字元 LF；SRT／VTT 檔尾有換行，LRC／TXT 檔尾沒有換行。
  另外三個資料夾是同一份內容的變體，只改編碼標記與換行字元：
  - `utf8bom-lf/`：檔頭加 BOM（EF BB BF）
  - `utf8-crlf/`：換行字元改成 CRLF
  - `utf8bom-crlf/`：兩者都改
- `SHA256SUMS` 是 32 個字幕檔的雜湊。

## 測試影片

畫面上方燒進時間碼（時:分:秒.毫秒，10 fps），長 1:01:00，沒有語音，只用來看字幕出現的時間。每秒一個關鍵格，播放器 seek 到整數秒時會落在那一格。

```
ffmpeg -f lavfi -i "color=c=0x202020:s=640x360:r=10:d=3660" -f lavfi -i "anullsrc=r=16000:cl=mono" -t 3660 \
  -vf "drawtext=fontfile=<等寬字型>:text='%{pts\:hms}':fontsize=40:fontcolor=white:x=(w-tw)/2:y=24:box=1:boxcolor=0x000000@0.6:boxborderw=8" \
  -c:v libx264 -preset veryfast -crf 32 -g 10 -keyint_min 10 -sc_threshold 0 -pix_fmt yuv420p \
  -c:a aac -b:a 16k -shortest -movflags +faststart subtitle-test.mp4
```

Windows 上 `<等寬字型>` 可以用 `C\:/Windows/Fonts/consola.ttf`（冒號要跳脫）。播放器自動載入字幕時，字幕檔要和影片同檔名、放在同一個資料夾。

## 每個時間點應該看到什麼

SRT／VTT，Multi-Speaker 開。顏色：S0 白（不加標籤）、S1 黃 `#FFDD55`、S2 青 `#66CCFF`、S3 綠 `#7FE0A0`。
判讀時以畫面上的時間碼為準：截到的那一格是什麼時間，字幕就要符合那個時間。

| 時間 | 應該看到 |
|---|---|
| 0.9 | 沒有字幕 |
| 1.1 | 白「[S0] 字幕測試開始。」 |
| 4.5 | 黃「[S1] 黃色的說話者。」 |
| 6.5 | 黃「[S1] こんにちは。」與青「[S2] 青色的說話者。」同時（只重疊 6.500–6.510） |
| 7.5 | 青「[S2] 青色的說話者。」 |
| 10 | 綠「[S3] 綠色的說話者。」 |
| 16.2 | 黃「[S1] 我們下週一要交報告，資料我已經整理好了，等一下寄給大家。」與白「[S0] 對。」**同時**（對：15.97–16.77，ADR-0008） |
| 23 | 白「[S0] A & B <笑> --> x」照字面 |
| 26 | 黃「[S1] 1 < 2 && 3 > 2」照字面 |
| 29 | 青「[S2] <i>はい</i>です」：VTT 照字面顯示 `<i>はい</i>`；SRT 沒有跳脫的寫法，播放器會把「はい」變成斜體（已知限制，見 `output_format._srt`） |
| 32 | 綠「[S3] ♪～「引號」『括號』…！？ 😊♡」 |
| 35.1 | 白「[S0] 這行從三十四點九九六秒開始」（34.996 秒 → 35.000 開始） |
| 59.9 | 沒有字幕（上一行 36.5 結束） |
| 60.1 | 黃「[S1] 這行從五十九點九九六秒開始」（1:00.000 開始） |
| 64、68、72 | 青，日文長句依逐字時間拆成三則：「今日はとてもいい天気ですね、」「みんなで公園に行ってゆっくり休んでから、」「おいしいご飯を食べに行きましょう。」 |
| 80、84 | 綠，中文長句拆成兩則：「這是一句很長的中文字幕，用來檢查超過三十二個全形字寬時，」「會不會依照逐字時間拆成好幾則字幕。」 |
| 3600.5 | 白「[S0] 跨過一小時。」（59:59.5–1:00:01.5） |
| 3604.9 | 沒有字幕 |
| 3605.1 | 黃「[S1] 這行在一小時零五秒開始」（1:00:05.000 開始） |
| 3652 | 白「[S0] 最後一行。」 |

Multi-Speaker 關：沒有說話者標記、不上色；沒有標記的行都算同一位說話者、不重疊（ADR-0008），所以 16.2 秒只看到「對。」，S1 那一行在 15.97 結束。

LRC 沒有結束時間：每一行顯示到下一行開始；`[59:59.50]`、`[60:05.00]`、`[60:50.00]` 的分鐘數超過 59。
要看的是：第一行在不在、時間對不對、`[S0]` 這類說話者標記是照字面顯示還是被當成 LRC 的標籤吃掉、特殊字元。

TXT：19 行，每行一句；看中文與日文會不會變亂碼、換行是否正確。
